# API Specification & Conventions

> SmartDroneInspection API — REST · ASP.NET Core 9 · OpenAPI 3.0 / Scalar

## 1. Global API Standards

- **Base URL**: `https://localhost:7080/api/v{version}`
- **Current Version**: `v1` (configured via `Asp.Versioning`)
- **Interactive Documentation**:
  - Scalar UI: `https://localhost:7080/scalar/v1` (Development only)
  - OpenAPI JSON: `https://localhost:7080/openapi/v1.json`

---

## 2. Authentication & Authorization

All requests to protected endpoints require a valid JWT Bearer token in the `Authorization` header:

```http
Authorization: Bearer <access_token>
```

### Roles (`Domain/Common/Roles.cs`)
- `Administrator`: Full system and tenant management.
- `InspectionManager`: Plan inspections, review reports, approve requests.
- `Inspector`: Execute inspections, upload findings, log missions.
- `MaintenanceEngineer`: Review defect tickets, execute repairs, log resolutions.
- `Viewer`: Read-only access to assets, dashboards, and approved reports.

---

## 3. Rate Limiting Policies

| Policy | Target Endpoints | Limit | Rejection |
|--------|------------------|-------|-----------|
| `auth` | `/api/v1/auth/login`, `/api/v1/auth/refresh` | 10 requests / minute per IP | `429 Too Many Requests` |
| `global` | All other API endpoints | 300 requests / minute per IP | `429 Too Many Requests` |

---

## 4. Error Handling (RFC 7807 ProblemDetails)

All error responses adhere to the RFC 7807 standard generated by `GlobalExceptionHandler`:

```json
{
  "type": "https://tools.ietf.org/html/rfc7807",
  "title": "Asset code 'AST-001' already exists",
  "status": 409,
  "detail": null,
  "instance": "/api/v1/assets"
}
```

### HTTP Status Code Mapping

| Status Code | Reason | Cause |
|-------------|--------|-------|
| `200 OK` | Request succeeded | Successful GET, PUT, PATCH |
| `201 Created` | Resource created | Successful POST (includes `Location` header) |
| `204 No Content` | Deleted successfully | Successful DELETE |
| `400 Bad Request` | Validation failure | FluentValidation rule violated |
| `401 Unauthorized` | Unauthenticated | Missing / expired / invalid JWT token |
| `403 Forbidden` | Access denied | User role not authorized |
| `404 Not Found` | Resource not found | Invalid entity Id (`KeyNotFoundException`) |
| `409 Conflict` | Business rule conflict | Duplicate unique code, invalid lifecycle state |
| `429 Too Many Requests`| Rate limit exceeded | Exceeded window limits |
| `500 Internal Server Error`| Unexpected server fault | Unhandled exception (safe generic message) |

## 5. Core API Endpoints Catalog

### 5.1 Authentication (`/api/v1/auth`)

| Method | Endpoint | Auth / Role | Description |
|--------|----------|-------------|-------------|
| `POST` | `/api/v1/auth/login` | Anonymous (Rate limited) | Authenticate user & issue tokens |
| `POST` | `/api/v1/auth/refresh` | Anonymous (Rate limited) | Rotate refresh token & issue new access token |

### 5.2 Assets (`/api/v1/assets`)

| Method | Endpoint | Auth / Role | Description |
|--------|----------|-------------|-------------|
| `GET` | `/api/v1/assets` | Authenticated | Paged asset list with search and sorting |
| `GET` | `/api/v1/assets/{id}` | Authenticated | Get single asset details |
| `POST` | `/api/v1/assets` | `Admin`, `InspectionManager` | Create a new asset |
| `PUT` | `/api/v1/assets/{id}` | `Admin`, `InspectionManager` | Update asset profile |
| `DELETE`| `/api/v1/assets/{id}` | `Admin` | Soft-delete asset |

### 5.3 Planning & Schedules (`/api/v1/plans`)

| Method | Endpoint | Auth / Role | Description |
|--------|----------|-------------|-------------|
| `GET` | `/api/v1/plans` | Authenticated | List inspection plans |
| `POST` | `/api/v1/plans` | `InspectionManager` | Create inspection plan & assign schedules |
| `GET` | `/api/v1/plans/calendar` | Authenticated | Get calendar events for inspection timeline |

### 5.4 Missions & Drone Integration (`/api/v1/missions`)

| Method | Endpoint | Auth / Role | Description |
|--------|----------|-------------|-------------|
| `POST` | `/api/v1/missions/request` | `InspectionManager` | Dispatch mission request to SmartDroneHub |
| `GET` | `/api/v1/missions/{id}/status` | Authenticated | Get current mission execution status |
| `GET` | `/api/v1/missions/{id}/telemetry`| Authenticated | Get mission flight telemetry data |
| `POST` | `/api/v1/missions/{id}/images` | `Inspector` | Upload inspection images to MinIO |

### 5.5 Reports & Maintenance (`/api/v1/reports`, `/api/v1/tickets`)

| Method | Endpoint | Auth / Role | Description |
|--------|----------|-------------|-------------|
| `GET` | `/api/v1/reports/{id}` | Authenticated | View inspection report with findings & defects |
| `POST` | `/api/v1/reports/{id}/approve`| `InspectionManager` | Approve report and spawn maintenance tickets |
| `GET` | `/api/v1/tickets` | Authenticated | List maintenance tickets (filter by assigned engineer)|
| `PATCH`| `/api/v1/tickets/{id}/status` | `MaintenanceEngineer` | Update ticket repair status & resolution notes |

### 5.6 AI & Knowledge Retrieval (`/api/v1/ai`)

| Method | Endpoint | Auth / Role | Description |
|--------|----------|-------------|-------------|
| `POST` | `/api/v1/ai/analyze-images` | `Inspector`, `Manager` | Trigger Vision AI defect detection on images |
| `POST` | `/api/v1/ai/knowledge/search`| Authenticated | Vector similarity search for past repair cases |
