# Architecture

Architecture is documented separately for each client and server so contributors can find the conventions for the repository they are changing.

- [Backend architecture](backend-architecture/): Spring Boot, Spring Modulith, modules, persistence, and integrations.
- [Frontend architecture](frontend-architecture/): React structure, state, routing, and API access.
- [Mobile architecture](mobile-architecture/): Flutter features, Riverpod state, networking, and secure storage.
