# Coding Conventions

To ensure consistency and high engineering quality across the 4-member team, all contributions must adhere to the following conventions:

- **[Backend Java conventions](backend-java/)**: Spring Boot, Spring Modulith, feature-owned modules, DTO placement, validation, and error handling.
- **[Frontend React conventions](frontend-react/)**: feature-based structure, strict TypeScript, TanStack Query, and Zustand.
- **[Mobile Flutter conventions](mobile-flutter/)**: Clean Architecture, Riverpod 3, GoRouter, and Dio.
- **[Git and pull request workflow](git-and-pull-requests/)**: Conventional Commits, branch naming, review, and merge rules.
