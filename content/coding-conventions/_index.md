# Team Coding Conventions

To ensure consistency and high engineering quality across the 4-member team, all contributions must adhere to the following conventions:

* **[Backend Java Conventions](backend-java.md)**: Spring Boot, Spring Modulith, feature-owned modules, DTO placement, validation, and error handling.
* **[Frontend React Conventions](frontend-react.md)**: Feature-based folder structure, TypeScript strict, TanStack Query key factories, Zustand.
* **[Mobile Flutter Conventions](flutter-mobile.md)**: Clean Architecture, Riverpod 3, GoRouter, Dio interceptor.
* **[Git Workflow & PR Guidelines](git-workflow.md)**: Conventional Commits, branch naming, PR checklist.
