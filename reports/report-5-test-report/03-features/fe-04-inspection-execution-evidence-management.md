# FE-04: Inspection Execution and Evidence Management

## Scope baseline

**Current target scope:** The `inspections` module now implements the MF3 evidence slice of FE-04: scoped evidence upload with server-computed checksum and idempotent retry, evidence listing and streaming, and the assigned Inspector's substantive evidence-quality decision that gates AI analysis and report drafting. Assignment acceptance and checklist execution (the `WF3-001` preconditions) remain unimplemented — there is no HTTP endpoint that creates an inspection — so `WF3-001` stays historical evidence. Manual drone piloting remains outside the platform target.

**Historical v1 scope record:** The earlier Flutter/Web and backend baseline supported assignment acceptance, inspection sessions, evidence upload/retry and metadata. Preserve the v1 scope and evidence below as historical only.
