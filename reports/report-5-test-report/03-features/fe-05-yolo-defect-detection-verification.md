# FE-05: YOLO-assisted Defect Detection and Verification

## Scope baseline

**Current target scope:** The `inspections` module implements the MF3 finding slice of FE-05: advisory AI candidates that stay separate from human-verified findings, a manual finding path that remains available when inference is refused or fails, and the qualified reviewer's decision on a finding. Report 3 requires that manual entry survives an AI outage, so the manual path is not conditional on AI availability.

**Historical v1 scope record:** The earlier backend baseline included a YOLO adapter contract and candidate-review behavior. Preserve the v1 notes below as historical evidence; they are not current runtime guarantees.
