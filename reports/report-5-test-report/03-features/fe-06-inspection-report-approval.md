# FE-06: Inspection Report and Approval

## Scope baseline

WF3 combines checklist results, evidence and verified findings into a versioned report. Inspector submission is followed by peer review by another Inspector and Service Manager release. On Client acceptance the owning inspection transitions to `COMPLETED`. Accepted versions are immutable; corrections create a new version and preserve approval history. Client acceptance is the inspection billing milestone. The Inspector may request an on-demand AI-assisted narrative draft for a `DRAFT` version; the draft remains human-reviewed and editable via the narrative endpoint.
