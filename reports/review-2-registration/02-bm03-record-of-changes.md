## 1. Summary of Scope Evolution Rationale
Following Review 1 committee feedback and Iteration 1 implementation findings, the project scope was refined to **increase real-world business depth and eliminate external unverified dependencies** while preserving the approved project code (`GFA26SE139`) and title:
1. **Elimination of External `SmartDroneHub` Dependency & Introduction of B2B Drone Leasing**: In v1.0, the platform depended on an external `SmartDroneHub` API for drone missions and telemetry. Because physical flight control and live RC telemetry are outside enterprise SaaS scope (and no live `SmartDroneHub` environment exists), the platform was elevated into a self-contained **Multi-Tenant Enterprise SaaS & B2B Drone Leasing Platform** with an internal platform drone pool (`platform_drones`), B2B lease contracts (`drone_leases`), customer fleet inventory (`drones`), recurring inspection schedules (`recurring_inspection_schedules`), and self-service aviation flight permit gates (`Ready for Flight`).
2. **Five-Role Governance Model**: Refined the v1.0 actors (`Administrator`, `Inspection Manager`, `Inspector`, `Maintenance Engineer`, `Viewer`) into 5 active operational roles across Platform and Customer Enterprise zones (`Platform Admin`, `Platform Manager`, `Organization Manager`, `Inspector`, `Maintenance Engineer`), replacing the passive `Viewer` role with role-scoped dashboards and adding `Platform Manager` to govern commercial SaaS subscriptions and B2B drone leasing with strict separation of duties.
3. **Technology Stack Standardization on Java 21 / Spring Boot 4.1 & Python FastAPI YOLO11**: Migrated the backend specification from `ASP.NET Core / EF Core / SignalR` to **`Java 21, Spring Boot 4.1.0, Spring Modulith 2.1.1, PostgreSQL 17 (pgvector), MinIO, and FastAPI (Ultralytics YOLO11)`** to leverage Spring Modulith's compile-time architectural verification, Testcontainers integration testing, and native Python PyTorch computer vision deployment.
4. **Concrete Engineering AI Features**: Grounded the three AI capabilities into verifiable, human-in-the-loop microservices: (1) **Self-hosted YOLO11 (`MBDD2025`) + Multimodal Fallback** for structural defect detection, (2) **Context-Grounded LLM Report Drafting** with mandatory author section verification, and (3) **RAG-Assisted Maintenance Scope Advisor** backed by `pgvector` (`repair_knowledge_chunks`) and Vietnamese/international civil engineering standards (`TCVN 9343:2012`, `EN 1504-9`, `ISO 12944-5`, `ASTM C1583`, `TCVN 9361:2012`).
